# Возвышение наружного рельса и колея

Читай этот файл при назначении возвышения в кривых и оформлении данных о нём на чертежах. Нормативные значения ниже даны с источниками; там, где источник не подтверждён, стоит пометка «уточнить» — такие значения нельзя принимать молча.

## 1. Расчётная формула

Для колеи 1520 мм возвышение по условию равновесия:

```
h = 12.5 · V² / R      [мм], V — км/ч, R — м
```

Источник: методика по определению возвышения наружного рельса ОАО «РЖД» / ПТЭ; константа следует из `h = S·V²/(g·R)` при расстоянии между осями рельсов S ≈ 1,6 м с переводом единиц. Расчёт ведут по максимальной допускаемой скорости или по приведённой средневзвешенной скорости поездопотока (что именно — задаёт владелец проекта).

## 2. Подтверждённые нормативные границы

| Параметр | Значение | Источник |
|---|---|---|
| Возвышение устраивается | кривые R ≤ 4000 м | методика ОАО «РЖД» по возвышению |
| Максимальное возвышение | **150 мм** (с учётом допусков на содержание) | распоряжение ОАО «РЖД» от 14.11.2016 № 2288р; также техусловия устройства возвышения (docs.cntd.ru/document/1200102112) |
| Минимально устраиваемое | 15 мм: при расчёте меньше 15 мм возвышение **не устраивается** (кроме закрестовинных кривых и кривых на стрелочных переводах) | нормативная и учебная литература по рельсовой колее — **уточнить по действующей редакции методики РЖД** |
| Непогашенное ускорение a_неп | ≤ 0,7 м/с² (типовое допускаемое; в отдельных случаях до 1,0 м/с²) | нормы устройства рельсовой колеи / отраслевые инструкции — **точное значение уточнить по категории линии** |
| Отвод возвышения | уклоны отвода — по распоряжению ОАО «РЖД» от 14.12.2016 № 2540р (для проектных организаций); при переходных кривых отвод, как правило, линейный в пределах клотоиды | распоряжение № 2540р; **параметры (величины уклонов отвода, длины) — по тексту распоряжения** |

Связь недостатка возвышения с непогашенным ускорением (согласовано с константой 12,5):

```
a_неп = (h_равн − h) / 163.1   [м/с²],  163.1 = 1000·S/g, S = 1.6 м
```

## 3. Расчёт через скрипт

```bash
uv run python skills/railway-design/scripts/cant_calc.py --curves "100:800,80:1200,60:3000"
```

Вход: пары `V:R` (км/ч : м); опционально `--max-cant`, `--min-cant`, `--radius-no-cant`, `--acc-limit` (переопределение норм по заданию владельца). Выход (JSON): для каждой пары `h_eq_mm` (равновесное), `h_applied_mm` (применённое), `status` (`normal` / `below_minimum` / `exceeds_max` / `not_required`), `a_nep_ms2`, `v_equilibrium_kmh`, предупреждения; в блоке `constants.sources` — текстовые источники каждого норматива. Скрипт флагует нарушения, но не «подгоняет» проектные значения молча.

## 4. Отображение на чертежах

- На плане: возвышение указывают в ведомости кривых/у пикетажа начала и конца отвода (при переходных кривых отвод идёт в пределах L; точки НПК/КПК совпадают с НК/КК). Подпись в форме «h = 125» на слое `RW-GRADE` (`annotation` → `create_text`).
- В графе уклонов продольного профиля возвышение не показывается — оно на плане и в ведомости кривых. Не дублируй данные в двух местах с разными значениями: источник истины один — расчётная таблица JSON.
- Колея 1520 мм подписывается в штампе/ведомости; допуски содержания колеи — **уточнить по действующей редакции ПТЭ**, на чертеже не проставлять без задания.

## 5. Что проверяет человек

- Соответствие выбранного h действующей редакции методики РЖД (документы обновляются; 2288р/2540р могут быть заменены новыми актами — проверяй актуальность).
- Учёт скоростей грузового и пассажирского движения (приведённая скорость), рекуперативного торможения, холодных/горячих условий — за пределами скрипта.
- Согласование h с длиной переходной кривой (уклон отвода) — проектное решение.
