# Продольный профиль

Читай этот файл при построении продольного профиля: сетка по СПДС, чёрный и красный профили, вертикальные кривые, рабочие отметки.

## 1. Состав листа

Продольный профиль размещается над сеткой (шаблонкой). Сетка — таблица граф по СПДС; типовой состав (снизу вверх):

1. **Пикетаж** — номера пикетов (ПК);
2. **Расстояния** — между точками перелома (плюсовыми точками);
3. **Фактические отметки земли** (чёрные отметки) — по уклонозасечке;
4. **Проектные отметки** (красные отметки) — по бровке земляного полотна / оси;
5. **Уклоны (в тысячных)** — графы «уклон / расстояние»: вертикальная линия на переломе, сверху уклон в ‰, снизу горизонтальное расстояние; на вертикальных кривых — их элементы;
6. **Развернутый план пути** — схематический план: прямые и кривые (схема «план трассы развёрнутый»), прямые участки — горизонтальная линия, кривые — скобки вверх/вниз по направлению поворота, подписи R, L, θ.

Состав и высоты граф, формы подписей зависят от отраслевых норм оформления; **уточняй по действующей редакции стандартов СПДС (ГОСТ Р 21.1101) и норм рабочей документации железнодорожных путей (ГОСТ 21.611)** — не копируй ширины «по памяти». Заготовка сетки: `scripts/profile_grid.py` (см. §5).

## 2. Масштабы

Типовые (уточняются заданием и нормами):

- горизонтальный: 1:10000, 1:5000, 1:2000, 1:1000;
- вертикальный: 1:1000, 1:500, 1:200, 1:100 (обычно на порядок крупнее горизонтального).

**Правило единиц:** модель профиля — миллиметры листа (сетка 1:1 в мм); отметки и расстояния пересчитывай в мм листа: `x_мм = (ПК_точки − ПК_начало)·1000/M_гор`, `y_мм = H·1000/M_верт`. Не смешивай с метрами модели плана трассы (см. layers-and-standards.md).

## 3. Линии профиля

- **Земляной (чёрный) профиль** — ломаная по фактическим отметкам земли в точках уклонозасечки (пересечения оси с горизонталями и характерными точками рельефа). Чертится `entity` → `create_polyline` по точкам `(x_мм, y_мм)`, слой `RW-PROF-GROUND`.
- **Проектный (красный) профиль** — ломаная проектных отметок (бровка/ось земляного полотна), слой `RW-PROF-DESIGN`. Переломы назначает проектировщик по категории линии и грунтовым условиям; величины максимальных уклонов — **уточнить по СТН Ц-01-95 / нормам проектирования** (не принимай по памяти).
- **Существующие/пересекаемые** коммуникации и сооружения — слой `RW-PROF-EXIST` (штрих).
- **Скважины/шурфы** — слой `RW-BOREHOLE`: колонка с абсолютной отметкой устья, глубинами и описанием грунтов (данные геологии подставляет пользователь).

## 4. Уклоны и вертикальные кривые

- Уклон в тысячных: `i = ΔH / L·1000` (‰). Запись в графе уклонов: «6» означает 0,006.
- **Вертикальные кривые** сопрягают переломы проектного профиля (точная геометрия):
  - тангенс вертикальной кривой: `Tв = Rв · |i₁ − i₂| / 2` (i в долях единицы);
  - длина: `Kв = 2Tв`;
  - биссектриса (подъём/понижение от перелома): `Бв = Tв² / (2Rв)`; поправка отметки в точке на расстоянии x от начала кривой: `y = x² / (2Rв)`.
  - Выпуклые кривые (перелом «вниз-вверх» убывающих уклонов) и вогнутые различаются знаком поправки.
  - Радиусы Rв и условия обязательного устройства вертикальных кривых зависят от категории линии и алгебраической разности уклонов — **уточнить по действующим нормам проектирования** (значения из памяти не принимать).
- **Рабочая отметка** = проектная отметка − земляная отметка: положительная — насыпь, отрицательная — выемка. Подписывается у проектной линии.

## 5. Заготовка сетки скриптом

```bash
uv run python skills/railway-design/scripts/profile_grid.py \
  --length-m 3000 --start-pk 0 --h-scale 5000 --v-scale 1000 --out profile_grid.dxf
```

Вход: длина участка (м), начало в пикетах, масштабы. Выход: DXF (сетка в мм листа: горизонтальные разделители граф, вертикали по пикетам, подписи «ПК N», названия граф в левой маргинации) + JSON-манифест (файл, SHA-256, число примитивов, границы). Слои берутся из `assets/layer-scheme.json` (`RW-GRID`, `RW-TEXT`). Свой набор граф: `--rows "Развернутый план пути:20,Уклоны:10,..."`.

## 6. Верификация (обязательная)

1. После нанесения чёрного профиля: `entity.list` по слою `RW-PROF-GROUND` — число вершин полилинии = числу точек уклонозасечки; контрольные отметки совпадают с исходными данными.
2. Проектная линия: пересчитай уклоны между переломами из координат чертежа и сравни с заданными (допуск — точность округления ‰).
3. Рабочие отметки в контрольных сечениях посчитай вручную из отметок и сравни с подписями.
4. `drawing` → `render_preview` всего листа: сетка не перекрывает профиль, тексты читаемы, графы не «пустые».
5. Нормативные проверки (максимальные уклоны, длины площадок, радиусы Rв) — за человеком.
