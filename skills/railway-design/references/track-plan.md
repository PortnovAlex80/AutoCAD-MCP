# План трассы: элементы, пикетаж, расчёт

Читай этот файл при разбивке плана пути: прямые вставки, круговые кривые, переходные клотоиды, пикетаж.

## 1. Состав плана

План трассы — проекция оси пути на горизонтальную плоскость. Состоит из:

- **прямых вставок** (участки постоянного направления);
- **круговых кривых** радиуса R с углом поворота θ (вершина угла — ВУ);
- **переходных кривых** (клотоид) длиной L на подходах к круговым — кривизна меняется линейно по длине от 0 до 1/R.

Точки: **ВУ** (вершина угла поворота), **НК** (начало кривой), **КК** (конец кривой), **НКК/ККК** (начало/конец круговой кривой при наличии переходных), **СЦ** (середина круговой кривой; в безпереходной схеме — середина кривой СК), **Ц** (центр круговой кривой). Определения — в [glossary.md](glossary.md).

## 2. Точные формулы (чистая геометрия)

### 2.1 Круговая кривая без переходных

| Элемент | Формула |
|---|---|
| Тангенс T | `T = R·tan(θ/2)` |
| Длина кривой K | `K = R·θ_рад` |
| Биссектриса Б | `Б = R·(sec(θ/2) − 1)` |
| Домер Д | `Д = 2T − K` |

### 2.2 С переходными клотоидами

Параметр клотоиды: `C = R·L`. Угол клотоиды в конце: `β = L / (2R)` (рад).

Сдвижки (точные ряды Френеля, см. `scripts/clothoid_points.py`):

- `m = X_s − R·sin β` (сдвижка по тангенсу), где `X_s = L − L³/(40R²) + L⁵/(3456R⁴) …`
- `p = Y_s − R·(1 − cos β)` (сдвижка к центру), где `Y_s = L²/(6R) − L⁴/(336R³) + …`

Условие размещения: `2β < θ`, иначе переходные кривые не помещаются (скрипт вернёт ошибку).

Элементы составной кривой:

| Элемент | Формула |
|---|---|
| Тангенс с переходными Tp | `Tp = (R + p)·tan(θ/2) + m` |
| Длина круговой части K₀ | `K₀ = R·(θ − 2β)` |
| Полная длина Kfull | `Kfull = K₀ + 2L` |
| Биссектриса Бp | `Бp = (R + p)·sec(θ/2) − R` |
| Домер Д | `Д = 2Tp − Kfull` |

Координаты характерных точек: система с началом в НК, +x по первой касательной к ВУ. НКК = конец клотоиды по Френелю `(X_s, Y_s)`; ККК и КК — зеркальные отражения НКК и НК относительно биссектрисы ВУ–Ц (гарантирует принадлежность окружности и касательность второй клотоиды). Скрипт выдаёт их готовыми.

## 3. Расчёт через скрипт

```bash
uv run python skills/railway-design/scripts/track_geometry.py \
  --angle-deg 24.35 --radius 800 --spiral 80 --station-vu 2456.78 --turn left
```

Выход (JSON): `elements.simple` (T/K/Б/Д всегда), `elements.augmented` (C, β, m, p, Tp, K₀, Kfull, Бp, Д — при L>0), `coordinates` (nk, vu, nkk, kkk, kk, sc, center — метры), `chainage` (метры + формат `ПКNN+NN.NN`). Без `--station-vu` блок пикетажа опускается.

Клотоида для черчения:

```bash
uv run python skills/railway-design/scripts/clothoid_points.py \
  --radius 800 --length 80 --points 33 --origin-x <X_НК> --origin-y <Y_НК> \
  --direction <дирекционный угол вставки, °> --side left
```

Выход: `points` — готовый массив вершин для `entity` → `create_polyline` (`closed=false`), `end_tangent_deg` — направление в конце клотоиды (для стыковки с дугой).

## 4. Пикетаж

- Пикетаж ведётся от начала трассы (**ПК0+00**), пикет = 100 м; плюсовые точки пишутся как ПК12+45,60.
- Расчёт от пикетажа ВУ: `ПК НК = ПК ВУ − Tp`; `ПК НКК = ПК НК + L`; `ПК ККК = ПК НКК + K₀`; `ПК КК = ПК ККК + L`; `ПК СЦ = ПК НКК + K₀/2`.
- **Уравнирование пикетажа (домер):** продолжение пикетажа по касательным длиннее пикетажа по кривой на Д. Точка, отмеренная по второй касательной на s метров от ВУ, имеет пикетаж `ПК ВУ + s − Д`. При переносе пикетажа за кривую всегда применяй домер; сам факт уравнивания фиксируй в расчётной таблице.
- Кривая лежит «за» ВУ: КК = ВУ + Tp по направлению второй касательной (не между НК и ВУ).

## 5. Черчение через MCP

- Прямые вставки: `entity` → `create_line` на слое `RW-AXIS-DES` (см. `assets/layer-scheme.json`).
- Круговая часть: `entity` → `create_arc` (`data: {cx, cy, radius, start_angle, end_angle}`) — центр и углы берутся из координат Ц/НКК/ККК скрипта. Дуга ARC точнее и легче полилинии.
- Переходные: `entity` → `create_polyline` из точек `clothoid_points.py`. Аппроксимация полилинией допустима при шаге, дающем стрелу прогиба хорды `f = Δl²/(8R)` в пределах допуска черчения (для R=800 м и допуска 0,1 мм листа при выводе 1:2000 — Δl до ~10 м; по умолчанию бери шаг ≤ 10 м).
- Вспомогательные линии (тангенсы НК–ВУ–КК, биссектриса) — на слой `RW-CONSTR` (`plot: false`).
- Пикетажные подписи и выноски ВУ/НК/КК/СЦ — `annotation` → `create_text`/`create_leader` на слое `RW-CHAINAGE`.

## 6. Ограничения и что проверяет человек

- Скрипт — геометрия одного угла поворота. Сопряжение нескольких углов (вставки между кривыми, реперные точки) планируешь ты: величины минимальных прямых вставок зависят от категории линии и скоростей — **уточнить по действующей редакции СТН Ц-01-95 / норм проектирования**; не принимай значений из памяти.
- Радиусы и длины переходных выбирает проектировщик по категории линии; скрипт только считает геометрию введённых значений.
- НК/КК должны лежать на оси с точностью построения: после черчения кривой сверь `entity.get` координат НКК/ККК с расчётом (допуск по контракту скилла).
