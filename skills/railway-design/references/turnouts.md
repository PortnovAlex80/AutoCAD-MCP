# Стрелочные переводы, съезды, глухие пересечения

Читай этот файл при нанесении стрелочных переводов на план пути. Важно: точные размеры перевода нельзя вывести из марки — они задаются альбомом типовых проектов.

## 1. Марка перевода и угол крестовины (точная геометрия)

Марка M определяет угол крестовины α однозначно:

```
α = arctan(1 / M),   cot α = M
```

| Марка | α | α в град-мин-сек |
|---|---|---|
| 1/9 | 6,340192° | 6° 20′ 24,7″ |
| 1/11 | 5,194429° | 5° 11′ 39,9″ |
| 1/18 | 3,179830° | 3° 10′ 47,4″ |
| 1/22 | 2,602562° | 2° 36′ 09,2″ |

Расчёт: `uv run python skills/railway-design/scripts/turnout_geometry.py --mark 1/11` — JSON с α (рад/°/DMS), тангенсом и котангенсом.

## 2. Типы и применение

- Типы по рельсу: **Р65, Р50** (цифра — масса погонного метра рельса, кг/м).
- Марки (типовое применение, **уточнять по нормам проектирования для конкретной категории линии и скорости**):
  - 1/9 — станционные, погрузочно-выгрузочные, соединительные пути;
  - 1/11 — приёмо-отправочные пути, стрелки на главных путях промежуточных станций;
  - 1/18, 1/22 — стрелки на главных путях при высоких скоростях (разъезды, обгонные пункты, обходы).
- Марку и тип перевода на конкретном объекте задаёт проект/владелец; агент не выбирает марку вместо проектировщика.

## 3. Размеры перевода: только из альбома

Полная длина перевода **Lп**, передний вылет **a** (от острия остряков до центра перевода) и задний вылет **b** (от центра перевода до торца крестовины; `a + b = Lп`) — величины альбомные: зависят от типа рельса, конструкции остряков и проекта. Типовые альбомы — проекты серии 2720 и др.

Встроенная справочная таблица скрипта (вывод `--table`) помечена `"verified": false` — **использовать для простановки размеров на чертеже нельзя**, только для прикидки габаритов на эскизе, с явной пометкой «уточнить по альбому». Если у пользователя есть данные альбома — передай их явно:

```bash
uv run python skills/railway-design/scripts/turnout_geometry.py \
  --mark 1/11 --length 33.35 --a 14.44 --rail Р65
```

Выход дополнится `album: {length_m, a_m, b_m, verified}`; `b` вычисляется как `Lп − a` (проверка согласованности: `0 < a < Lп`).

## 4. Съезды и глухие пересечения

- **Нормальный съезд** (соединение параллельных путей двумя переводами одной марки): расстояние между центрами переводов по прямому пути приближённо `L_центров ≈ E · M`, где E — расстояние между осями путей. Это аппроксимация классической схемы; точную разбивку (прямая вставка между крестовиной и остряками, радиусы переводных кривых) — по альбому. Скрипт: `--crossover 5.3` вернёт `crossover.center_distance_approx_m` с `"approximation": true`.
- **Глухое пересечение** — без подвижных сердечников (крестовины навстречу); углы и размеры — по альбому, скрипт их не моделирует.
- **Стрелочная улица / сплетение путей** — последовательность съездов; пикетаж считай по центрам переводов, длины прямых вставок между смежными стрелками — **уточнить по нормам проектирования**.

## 5. Отображение на плане (MCP)

- Условное обозначение перевода на оси: линия ответвления по углу α + подпись марки (`2/9п`, «1/11» и т.п. по принятой форме — **уточнить форму условных обозначений по нормам оформления**) на слое `RW-TURNOUT`.
  - ответвление: `entity` → `create_line` от центра перевода под углом α (направление `atan2(sin α, cos α)` по стороне отклонения);
  - подпись: `annotation` → `create_text` высотой по масштабу листа.
- Повторяющиеся переводы: определите блок (`block` → `define` с геометрией условного обозначения) и вставляйте `block` → `insert` с поворотом на угол трассы в точке центра перевода; атрибуты марки — `insert_with_attributes`.
- Центр перевода (ЦП) и пикетаж подписываются на слое `RW-CHAINAGE`.

## 6. Ограничения

- Скрипт даёт угол и согласованность альбомных данных, но не «проектирует» горловину: расстановку переводов, взаимозаменяемость, длины вставок выполняет проектировщик.
- Все альбомные числа без явного ввода пользователем считаются неподтверждёнными: на чертеже их не проставлять.
